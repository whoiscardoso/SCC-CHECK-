SCC CHECK | AUTOLIST — INSTALAÇÃO COMO APLICATIVO (PWA) NO GITHUB PAGES

1. Extraia todos os arquivos deste pacote.
2. No repositório GitHub que publica o sistema, coloque TODOS os arquivos abaixo na pasta publicada (normalmente a raiz):
   - index.html
   - manifest.webmanifest
   - service-worker.js
   - icon-192.png
   - icon-512.png
   - .nojekyll (arquivo vazio, incluído no pacote)
3. Faça commit e push.
4. No GitHub, abra Settings > Pages e confirme a publicação pela branch/pasta correta (por exemplo, Deploy from a branch > main > /(root), ou a pasta configurada no projeto).
5. Aguarde o GitHub Pages publicar e abra o endereço HTTPS do site.
6. No Chrome, use o ícone Instalar na barra de endereço ou Menu > Transmitir, salvar e compartilhar > Instalar página como app (o texto pode variar).

IMPORTANTE PARA GITHUB PAGES:
- Mantenha os cinco arquivos do PWA no MESMO diretório do index.html publicado.
- O pacote está configurado com caminhos relativos para funcionar também em repositórios de projeto (URL no formato usuario.github.io/nome-do-repositorio/).
- Se o seu HTML principal tiver outro nome, renomeie-o para index.html.
- Publique por HTTPS usando GitHub Pages; abrir o HTML diretamente pelo computador (file://) não habilita instalação PWA.
- Login, Supabase e consultas continuam dependendo de internet.
- Ao atualizar o sistema, publique novamente os arquivos e atualize a versão do cache no service-worker.js se necessário.

O HTML do sistema foi mantido; esta adaptação acrescenta a estrutura PWA e os arquivos necessários para instalação.
